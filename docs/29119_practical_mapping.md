# ISO/IEC/IEEE 29119 Practical Mapping (original summary, not standard text)

29119-2:2021 defines generic test processes for governing, managing and implementing testing across lifecycle models. 29119-3:2021 defines test documentation templates produced by those processes.

For this lab use the following practical documentation set:
- Test Strategy: objectives, scope, streams, test levels/types, risk-based approach, environments/data, automation/evaluation, governance, metrics, defect management, reporting, entry/exit philosophy, roles, assumptions/constraints.
- Test Plan: test context/scope, test basis, test items, features to test/not test, approach, resources, environment, data, schedule, dependencies, risks, deliverables, monitoring/control, incident/defect process, completion criteria, approvals.
- Test Status Report: period/build, execution, coverage, defects, AI metrics, agent metrics, risks/blockers, forecast/actions.
- Test Completion Report: scope completed, deviations, results, unresolved defects, residual risks, criteria assessment, recommendation, lessons/actions.

Use this as a working template only. It intentionally does not reproduce the copyrighted ISO/IEC/IEEE text.
