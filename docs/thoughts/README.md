# Thoughts / Proposals

This folder contains future-state ideas, orchestration proposals, and design notes that are intentionally **not yet treated as implemented behavior**.

Use this folder to preserve decisions and next-step concepts so a future contributor or AI assistant can resume work without relying on chat history.

## Rules

- A file here is a proposal / thought unless explicitly promoted into implementation documentation.
- Keep future orchestration and governance concepts here before implementation.
- When a proposal is implemented, move the relevant content into canonical docs or clearly mark the proposal as implemented and link the implementation.
- Do not treat a proposal as runtime truth.
