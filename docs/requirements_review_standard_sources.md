# Requirements Review Standard References

The Requirements Review Agent quality model is based on:

- ISO/IEC/IEEE 29148:2018 — Systems and software engineering — Life cycle processes — Requirements engineering.
- ISTQB Certified Tester Automotive Software Tester syllabus, which identifies the tester-relevant ISO 29148 requirement quality characteristics as verifiable, unambiguous, consistent, complete, and singular (atomic), and also notes feasible, appropriate, correct, conforming, comprehensible, and necessary characteristics.

The agent prompt operationalizes these characteristics as a review checklist; it does not reproduce the standard text.

Current ISO reference page: https://www.iso.org/standard/72089.html
ISTQB source: https://istqb.org/?download_id=3615&sdm_process_download=1
